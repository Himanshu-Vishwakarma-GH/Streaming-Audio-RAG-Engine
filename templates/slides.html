System Architecture

End-to-End System Topology

Hardware-optimized streaming pipeline connecting browser Web Audio to native C++ AVX2 kernels and ONNX runtimes.

Audio Ingress & Ring Buffer

  • Web Audio Capture: Captures microphone in 20ms frames (640 bytes at 16kHz 16-bit PCM).
  • Full-Duplex WebSocket: Real-time binary streaming between client browser and server.
  • Lock-Free SPSC Ring Buffer: Pre-allocated 1,024 frame capacity in C++ with 64-byte cache-line aligned atomic pointers (under 15ns push overhead).

Acoustics & Inference Pipeline

  • Silero VAD (ONNX): Frame-by-frame speech energy scoring with 80ms silence endpointing.
  • Early Intent Spotter: Triggers speculative retrieval when $P(\text{intent} \mid \text{prefix}) \ge 0.75$.
  • Dual-Layer Echo Gate: Mutes mic and recognition stream during audio playback to suppress self-listening loops.
SYSTEM INTEGRITY: Zero external cloud calls during retrieval. Entire inference loop runs locally on the host CPU.
